# Big Data con PySpark
{: .fs-9 }

El objetivo general de este curso es brindar a los estudiantes las bases necesarias para procesar y analizar grandes volúmenes de datos con Python y Apache Spark.
{: .fs-6 .fw-300 }

---
¡Aprende a trabajar con datos que no caben en una sola máquina! Este curso parte de Python y Pandas y avanza hacia el procesamiento distribuido con PySpark. Construirás pipelines ETL con arquitectura Medallion y Delta Lake, procesarás datos en tiempo real con Structured Streaming y entrenarás modelos de machine learning con MLlib.

Al finalizar el curso, los estudiantes habrán adquirido:

1. Una comprensión de los conceptos fundamentales del procesamiento distribuido, incluyendo particiones, evaluación perezosa, shuffles y planes de ejecución.
2. Experiencia práctica en la construcción, depuración y optimización de pipelines de datos con PySpark, Delta Lake y Structured Streaming.
3. La capacidad de analizar problemas de rendimiento, elegir la herramienta adecuada para cada volumen de datos y entrenar modelos con MLlib.
