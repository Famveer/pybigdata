# Labs

Programming lab sessions will help you practice Python, Pandas and PySpark with Jupyter notebooks.

You need Python 3.12 and Java 17+ with `JAVA_HOME` configured.

To setup the environment, you can use pyenv or conda (recommended). Then, install dependencies:

```sh
pip install -r requirements.txt
```

Download the requirements file [here](./../requirements.txt).
